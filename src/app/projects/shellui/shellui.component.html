Shellui

Shellui (shellui.com) is an open-source React and TypeScript microfrontend shell and CLI that gives apps one navigation and theme. Sign-in is unified across apps with OAuth, SAML SSO, magic links, and Supabase Auth. Django services use multi-tenant PostgreSQL schemas, signed webhooks, and Celery jobs with retries and an outbox. Each release is protected with 1,000+ tests and CI/CD on every pull request (web and Tauri).
